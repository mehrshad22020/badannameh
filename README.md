# بدن‌نامه 🫀 — اطلس سه‌بعدی آناتومی بدن انسان (فارسی)


سایتی کامل، فارسی و راست‌چین برای یادگیری آناتومی — با **مدل سه‌بعدی واقعی بدن انسان**، کاوشگر مغز، جزئیات عمیق هر عضو و بانک سوال.

**نمونه زنده:** https://mehrshad22020.github.io/badannameh/

## ▶️ اجرا

```bash
git clone https://github.com/mehrshad22020/badannameh.git
cd badannameh
python -m http.server 8080
# http://localhost:8080
```

(نمای سه‌بعدی به سرور محلی نیاز دارد؛ فایل‌های مدل با fetch خوانده می‌شوند.)

## 🛠 توسعه (برای مشارکت‌کنندگان)

ساختار کد در [README فنی](#-ساختار) پایین آمده. خلاصه:

- `js/v3d.js` — موتور Three.js: لودر باینری آتلاس، shader وضعیت هر قطعه، picking، جداسازی/انفجار/چیدمان
- `js/data-*.js` — محتوای فارسی (دستگاه‌ها، مغز، واژه‌نامه، زنانه، سوالات) — **اضافه‌کردن توضیح جدید = اضافه‌کردن یک آبجکت**
- `js/svg-*.js` — نمودارهای 2D (فرمت: رشته‌ی SVG با `data-organ`/`data-part`)
- `js/app.js` — روتر و صفحات (بدون فریم‌ورک)

**قواعد:** فارسی روان با نیم‌فاصله‌ی درست · ارجاع‌های `figure` باید در `FIGS` موجود باشند · تست دستی قبل از پوش · لایسنس assets را نقض نکنید.

## 🚀 استقرار روی سرور ایران (blog.doroodapp.ir)

روی خود سرور (دسترسی root):

```bash
bash <(curl -s https://raw.githubusercontent.com/mehrshad22020/badannameh/main/deploy/deploy-iran.sh)
```

یا:

```bash
git clone https://github.com/mehrshad22020/badannameh.git /tmp/badannameh-src
bash /tmp/badannameh-src/deploy/deploy-iran.sh
```

اسکریپت: کلون از گیت‌هاب → کپی به `/var/www/badannameh` → nginx برای `blog.doroodapp.ir` → certbot. به‌روزرسانی بعدی = اجرای دوباره.
