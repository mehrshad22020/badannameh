# بدن‌نامه 🫀 — اطلس سه‌بعدی آناتومی بدن انسان (فارسی)

سایتی کامل، فارسی و راست‌چین برای یادگیری آناتومی — با **مدل سه‌بعدی واقعی بدن انسان**، کاوشگر مغز، جزئیات عمیق هر عضو و بانک سوال.

## ▶️ اجرا

مدل سه‌بعدی فایل‌های محلی را با fetch می‌خواند؛ پس سایت را با سرور محلی باز کنید:

```bash
cd anatomy-fa
python -m http.server 8080
# سپس: http://localhost:8080
```

(باز کردن مستقیم index.html برای صفحات متنی کار می‌کند اما نمای سه‌بعدی به سرور محلی نیاز دارد.)

## ✨ امکانات

| بخش | توضیح |
|---|---|
| 🧬 مدل سه‌بعدی واقعی | آتلاس **BodyParts3D** (مرجع مرد بالغ، ۲۲۳۴ مش آناتومیک واقعی) — چرخش، زوم، کلیک روی هر ساختار |
| 🎯 جداسازی و انفجار | ساختار انتخابی از بقیه جدا می‌شود و دوربین روی آن زوم می‌کند؛ اسلایدر «انفجار لایه‌ها» دستگاه‌ها را از هم باز می‌کند |
| 🧠 کاوشگر مغز | تالاموس، هیپوکامپ، آمیگدال، مخچه و… **واقعاً سه‌بعدی** و جداشدنی + نماهای تشریحی 2D |
| 🔍 جستجوی هوشمند | تایپ کنید «قلب» — همه‌ی قطعات سه‌بعدی قلب انتخاب، جداسازی و با شرح فارسی باز می‌شوند |
| 🔬 جزئیات عمیق | ۸۸ عضو با شرح فارسی، زیربخش‌ها، نکات و نگاه بالینی + تصاویر تشریحی باکیفیت (Blausen / Gray) |
| 📝 آزمون | ۷۵ سوال دسته‌بندی‌شده با توضیح پاسخ و ثبت رکورد |

## 📁 ساختار

```
anatomy-fa/
├── index.html              ← صفحه اصلی (importmap سه‌بعدی)
├── css/style.css           ← طراحی «آزمایشگاه کالبد» (تیره/روشن)
├── assets/models/          ← آتلاس باینری واقعی (atlas.json + 15 chunk)
├── assets/img/             ← تصاویر تشریحی + manifest.json + CREDITS.md
└── js/
    ├── v3d.js              ← موتور Three.js (لودر باینری، انتخاب، جداسازی، انفجار)
    ├── data-fa-names.js    ← واژه‌نامه فارسی ساختارهای BodyParts3D
    ├── data-systems-*.js   ← شرح فارسی ۱۱ دستگاه
    ├── data-brain.js       ← ۲۹ ساختار مغز
    ├── data-quiz.js        ← ۷۵ سوال
    ├── svg-*.js            ← نمودارهای 2D (کمکی)
    └── app.js              ← منطق برنامه
```
